# Агент не регистрируется

*Решение проблем*

> Стол создан, но брокер его не видит: агент UDS не достучался до брокера или не прошёл проверку.

| Признак | Причина | Что делать |
|----|----|----|
| Стол долго в «Подготовке», потом ошибка | агент UDS не связался с брокером | С эталона проверьте доступ к адресу из команды подготовки (порт 443). |
| Ошибка сертификата в журнале агента | вариант «по имени»: ВМ не доверяет сертификату фронтов | Добавьте корень CA в «Образы» → «Внутренний адрес и корень CA» и подготовьте образ заново. |
| Агент работал, после смены VIP перестал | вариант «по серому адресу»: IP зашит в образ | Подготовьте образ заново новой командой. |
| Команда подготовки отвечает 403/404 | срок команды истёк | Нажмите «Новые команды»: каждая действует ограниченное время. |
| Брокер не может выйти из сеанса или перезагрузить стол | закрыт порт 43910 на столе | Команда подготовки открывает его в брандмауэре; проверьте групповые политики домена. |

Журнал агента UDS на Windows: `C:\Program Files\UDSActor\` и журнал событий «Приложение». Агенты VDI видны в разделе «Агенты».
