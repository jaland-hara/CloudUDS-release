# Столы без видеокарты

*Как устроено · обновлено 07.10.2026*

> Без vGPU всё рисует и сжимает процессор: офису хватает, 3D и CAD — нет. В общем облаке скорость зависит от соседей по хосту.

| Нагрузка | Без vGPU | С vGPU |
|----|----|----|
| Офис, почта, браузер, 1С | работает | работает |
| Видео в браузере, ВКС | работает, нагружает процессор стола | работает |
| 2D-черчение (AutoCAD 2D, Компас-График) | работает, крупные чертежи тормозят | работает |
| 3D на DirectX (AutoCAD 3D, Revit) | запускается, вращение рывками, процессор занят полностью | работает |
| 3D на OpenGL (SolidWorks, NX, CATIA, Creo, Компас-3D) | многие не запускаются: в RDP без видеокарты только программный OpenGL 1.1 | работает |

## Столы в общем публичном облаке

- **Скорость не гарантирована.** Когда соседи по хосту нагружают процессор, память или диск, стол тормозит без видимой причины внутри него.
- **Графика страдает первой.** Сжатие картинки идёт на процессоре стола; когда его не хватает, Windows снижает частоту кадров и качество.
- **Ресурсы с запасом.** Минимум 2 vCPU, для видео и ВКС — 4 vCPU. Тип ВМ с выделенными ядрами заметно ровнее.

Где нужна предсказуемая скорость (CAD, видеомонтаж, постоянные ВКС), используйте выделенные серверы vSphere или пулы с vGPU: [столы с vGPU](vgpu.md).
