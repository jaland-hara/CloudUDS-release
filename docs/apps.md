# Как установить программу, файл настроек или сертификат

*Руководство администратора → Ежедневная работа*

> Программа, файл настроек или сертификат ставится на столы без пересборки образа.

![схема](img/apps-1.svg)

**Схема текстом:**

1.  **Программы и настройки** — Добавить: программа, файл или сертификат
2.  **Назначить** — пулу (все его столы) или сотруднику (его столы)
3.  **Агент на столе** — применит за 5 минут; файлы в профиль — при входе
4.  **Статус** — на карточке элемента: применено и ошибки по столам
