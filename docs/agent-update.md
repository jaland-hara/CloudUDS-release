# Как обновляются агенты на столах

*Руководство администратора → Образы и пулы*

> Агент VDI обновляется сам, агент UDS — только вместе с образом.

**Агент VDI («Программы и настройки», профили)**

Обновляется **сам**. При каждом запуске (загрузка стола и каждые 5 минут) сверяется с кабинетом и, если версия на сервере другая, заменяет себя. Новая версия появляется после обновления панели. Выключенный стол обновится при включении, новый стол из старого образа — в первые 5 минут. Кнопка не нужна: на странице «Агенты» видно, сколько столов на старой версии (статус «1.1 → 1.2»); если стол включён, а версия не меняется больше 15 минут — у него нет связи с кабинетом.

**Агент UDS (actor)**

Сам **не обновляется**: он часть образа. Чтобы обновить: включите ВМ-источник (или эталонную ВМ vSphere), выполните команду подготовки «Образы» → «Свой образ» — она переставит агент UDS и VDI, выключите ВМ и выпустите новую версию пула («Обновить образ»). Свободные столы пересоздадутся сразу, выданные — после выхода сотрудника; личные постоянные — при пересоздании стола. Для ВМ без доступа к кабинету — офлайн-архив «Программы» → «Скачать агенты».

**Когда обновлять агент UDS:** вместе с обновлением брокера UDS — если в описании новой версии брокера сказано, что нужен новый агент.
