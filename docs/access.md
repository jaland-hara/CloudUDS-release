# Как выдать доступ к столам

*Руководство администратора → Сотрудники и доступ*

> Кто видит пул на портале: группы домена и персональный доступ.

![схема](img/access-1.svg)

**Схема текстом:**

1.  **Пулы столов** — откройте пул
2.  **Группы** — все участники группы получат стол этого пула
3.  **Персонально** — добавьте отдельного человека сверх групп
4.  **Портал /my/** — стол появится у сотрудника при следующем входе
