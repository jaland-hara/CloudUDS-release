# Запросы сотрудников

*Руководство администратора → Ежедневная работа*

> Заявки сотрудников на доступ к столам и как их разбирать.

![схема](img/requests-1.svg)

**Схема текстом:**

1.  **Сотрудник на портале** — просит: больше ресурсов, другой диск, не выключать стол по простою
2.  **Уведомление** — почта / Telegram, если включено событие «Новая заявка»
3.  **Работа → Запросы** — одобрить, отклонить или выдать другой пул персонально
4.  **Ресурсы** — панель выключит стол, сменит конфигурацию и включит — когда сотрудник нажмёт «Применить» или сразу по вашей кнопке (внимание)
5.  **Простой** — одобрение = персональное исключение из политики пула

Там же — «Экономия: выключенные столы»: какие столы политика выключила и когда. Открытые запросы уволенного сотрудника отклоняются при его отключении.
