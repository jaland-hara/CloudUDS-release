# Как удалить образ

*Руководство администратора → Образы и пулы*

> Почему кнопка «Удалить» у образа бывает неактивна и как освободить образ.

> **⚠ Внимание.**
>
> Кнопка «Удалить» у образа неактивна, пока образ используется хотя бы одним пулом.

![схема](img/del-image-1.svg)

**Схема текстом:**

1.  **Образы** — на карточке образа видно, какие пулы его используют
2.  **Удалите эти пулы** — или создайте их заново из другого образа, затем удалите старые (внимание)
3.  **Дождитесь «пул удалён»** — в журнале: пока есть снимки публикаций, том-шаблон занят
4.  **Образы → Удалить** — тома-шаблоны образа удаляются из облака

Образы поставки (встроенные) не удаляются, а убираются из каталога: их тома-шаблоны остаются в облаке и могут быть возвращены администратором.
