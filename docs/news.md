# Что нового

*Обслуживание · обновлено 07.10.2026*

> Изменения последних версий: клиент, кабинет и справка.

## 14.10.2026

- Столы с vGPU: сессии mstsc больше не зависают — сжатие H.264 перенесено с видеокарты на процессор; агент VDI исправляет уже созданные столы сам. [Подробнее](vgpu.md)
- RDP по UDP временно выключен на столах (только TCP): через туннель крупные датаграммы mstsc терялись, и сессия зависала.

## 13.10.2026

- Роли администраторов: Администратор, Оператор поддержки, Аудитор; назначение вручную и по группам домена, второй фактор по ролям. Оператор и аудитор не получают прав в UDS. [Как устроено](roles.md)
- Хранилища секретов и ключей: копия секретов установки в VK Cloud (Менеджер секретов, ключ в Barbican) или в хранилище организации (HashiCorp Vault, OpenBao, Deckhouse Stronghold, Barbican) — из кабинета и из мастера установки. [Подробнее](vault.md)
- «Состояние системы»: исправлена вёрстка, показана установленная версия выпуска.
- Обновление: туннели и шлюзы больше не застревают на прежних образах, пока узлы кабинета обновляются по очереди.

## 07.10.2026

- Клиент: качество «Авто» само снижает разрешение на медленном канале и возвращает полное, когда связь хорошая; «Экономия» рисует стол в пониженном разрешении. Узлы входа: TCP BBR — на дальних каналах с потерями поток в разы выше.
- «Безопасность» → «Белые списки адресов»: кабинет и портал открываются только с перечисленных адресов; аварийное снятие на сервере — [в справке](access-limit.md).
- Справка переделана: разделы, поиск, оглавление, «?» на каждом экране кабинета, раздел «Решение проблем».
- «Образы» → «Столы с vGPU»: команда настройки графики RDP для столов с NVIDIA (AVC444, 60 кадров/с).
- Клиент: видео 4K на Mac — 60 кадров/с вместо 13; аппаратное декодирование, обработка кадра 6 мс вместо 75.
- Клиент: метрики графики по `Alt`+`F`; буфер звука устойчивее на тяжёлом видео.
- Клиент для Windows: вход на стол без пароля после ADFS (как на Mac); туннель больше не закрывается после первого соединения mstsc (ошибка 0x204).

## 06.10.2026

- Вход на стол без пароля после ADFS: раздел «Вход без пароля», встроенный KDC Proxy, проверка цепочки.
- Клиент: камера Mac 720p, чистый звук микрофона, сжатие микрофона в режиме «Экономия», адаптивный буфер звука.
- Панель сеанса перетаскивается за шесть точек.

## 05.10.2026

- Панель сеанса как в HDX/Blast: устройства на лету, переподключение, мониторы, качество.
- Клиент переключается на другой фронт и туннель, если адрес недоступен; отчёты о недоступных адресах.
- Видео 4K без зависаний: H.264/AVC444.
