# Где смотреть журналы

*Решение проблем*

> Журналы клиента, стола и системы: где лежат и как включить подробный режим.

| Что | Где |
|----|----|
| Клиент CloudUDS, Windows | `%TEMP%\uds-launcher.log` |
| Клиент CloudUDS, macOS | `$TMPDIR/uds-launcher.log` (Терминал: `open $TMPDIR`) |
| Клиент CloudUDS, Linux | `/tmp/uds-launcher.log` |
| Подключения и действия | [«Журнал»](journal.md) в кабинете |
| Узлы и роли | [«Состояние системы»](health.md) |

## Подробный журнал клиента

Создайте пустой файл `.uds-debug-on` в домашней папке или во временной папке и перезапустите клиент. В журнал попадут подробности соединения, звука, камеры и строка метрик графики раз в 10 секунд. Удалите файл, когда разбор закончен: журнал растёт быстро.

> **Чего в журнале нет.**
>
> Пароли и закрытые ключи клиент не пишет даже в подробном режиме.
