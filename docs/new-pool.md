# Как создать пул столов

*Руководство администратора → Образы и пулы*

> Мастер создания пула: платформа, образ, размер, количество, доступ и устройства.

![схема](img/new-pool-1.svg)

**Схема текстом:**

1.  **Пулы столов → Создать** — мастер из семи шагов
2.  **Где создавать** — VK Cloud (или vSphere, если подключена опция)
3.  **Образ** — из каталога; для vSphere — только образы с эталонной ВМ
4.  **Как создавать** — vSphere: связанные, полные или мгновенные клоны, профиль vGPU
5.  **Конфигурация** — размер S/M/L или свой, тип диска или хранилище, сеть
6.  **Количество** — готовых столов, максимум; личные постоянные или временные
7.  **Доступ и устройства** — группы, способ входа (домен / без домена), политика
8.  **Создать** — первые столы — через 3–10 минут (внимание)

Личные постоянные — стол закрепляется за сотрудником и сохраняет всё; временные чистые — после выхода стол удаляется и создаётся заново (данные — только в профиле S3); временные с возвратом — стол после выхода достаётся следующему. Сеть и группу безопасности для групп AD можно задать заранее: «Пользователи» → «Размещение столов по группам».
