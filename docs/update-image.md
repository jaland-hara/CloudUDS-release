# Как обновить образ столов

*Руководство администратора → Образы и пулы*

> Новая версия образа для пула: свободные столы переходят сразу, выданные — после выхода сотрудника.

![схема](img/update-image-1.svg)

**Схема текстом:**

1.  **Обновите шаблон** — включите ВМ-источник, установите обновления, выключите
2.  **Образы → Добавить образ** — по ID этой ВМ — новые тома-шаблоны
3.  **Пул → Обновить образ** — выпускается новая версия публикации
4.  **Столы переходят** — свободные — сразу, выданные — после выхода сотрудника (внимание)

Опция VMware vSphere: шаг «Добавить образ» не нужен — обновите саму эталонную ВМ в vCenter (включить, обновить, выключить) и нажмите «Обновить образ» у пула: новая версия будет полной копией обновлённого эталона.
