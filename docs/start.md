# Что такое CloudUDS

*Начало работы*

> Виртуальные рабочие столы в VK Cloud: брокер OpenUDS 5 и всё, что нужно вокруг него.

CloudUDS выдаёт сотрудникам рабочие столы Windows и Linux, которые работают в облаке VK Cloud. Вся система — брокер, кабинет, портал, туннели — ставится в проект VK Cloud организации, столы создаются там же из образов облака. Сотрудник открывает портал, входит своей учётной записью и подключается к столу из приложения или из браузера.

По желанию заказчик может подключить и свой VMware vSphere — например, развернуть его на выделенных серверах VK Cloud Bare Metal as a Service ради столов с видеокартой NVIDIA vGPU: [пулы в VMware vSphere (опция)](vsphere.md).

## Из чего состоит

- **Брокер OpenUDS 5** — создаёт столы в VK Cloud, выдаёт их сотрудникам, следит за питанием.
- **Кабинет администратора** (этот сайт) — образы, пулы, доступ, политики, состояние системы.
- **Портал сотрудников** — вход (домен, ADFS, второй фактор) и плитки столов.
- **Клиент CloudUDS** — приложение для Windows, macOS, РЕД ОС, Astra и Альт: мониторы, звук, микрофон, камера, смарт-карты.
- **Агенты на столах** — агент UDS (вход, имя, домен) и агент VDI (программы, настройки, профили).
- **Фронты и туннели** — вход из интернета и из контура, отказоустойчивость.
