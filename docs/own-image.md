# Как добавить свой образ

*Руководство администратора → Образы и пулы*

> Своя ВМ с нужными программами становится образом каталога: команда подготовки, выключение, «Добавить образ».

![схема](img/own-image-1.svg)

Опция VMware vSphere: подготовьте ВМ той же командой в папке CloudUDS в vCenter, выключите её и добавьте: «Образы» → «Добавить образ» → VMware vSphere (выбор из списка или по ID vm-…). Образ сразу появится в мастере на платформе vSphere.
