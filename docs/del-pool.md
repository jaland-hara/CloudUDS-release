# Как удалить пул

*Руководство администратора → Образы и пулы*

> Удаление пула вместе со столами и всё, что кабинет приберёт за ним.

> **⚠ Внимание.**
>
> Все столы пула удаляются вместе с данными пользователей. Предупредите сотрудников заранее.

![схема](img/del-pool-1.svg)

**Схема текстом:**

1.  **Пулы столов** — откройте пул, проверьте, у кого есть столы
2.  **Удалить пул** — кнопка в карточке пула, рядом с «К списку пулов» (внимание)
3.  **Введите YES** — подтверждение нельзя сделать случайным кликом (внимание)
4.  **UDS удаляет столы** — ВМ, диски и снимки публикаций — несколько минут
5.  **Панель прибирает** — сервис пула, персональную группу, назначения программ
6.  **Журнал** — строка «пул удалён» — удаление завершено
