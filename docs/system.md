## Из OpenUDS 5 (VirtualCable, лицензия BSD-3)

Основа системы: брокер выдаёт столы, туннель доставляет картинку, агент на столе управляет входом, клиент показывает стол.

| Компонент | Где работает | Откуда установлен | Что изменено / дописано нами |
|----|----|----|----|
| **Брокер UDS** | сервер брокера: службы uds-broker (веб, REST API) и uds-taskmanager (фоновые задачи); /opt/uds/broker | исходники OpenUDS 5.0 — github.com/VirtualCable/broker (BSD-3), Python 3.12 / Django | патчи cloududs/broker/\*.patch: время кодов второго фактора (UTC), список клиентов для RED OS/Astra/Альт, имена томов OpenStack, данные ВМ пулов, включение и остановка столов, LDAPS и несколько контроллеров домена; транспорт «HTML5 RDP (Guacamole)» — broker/transports/HTML5Guac; провайдер «VMware vSphere» — broker/services/VSphere (ниже) |
| **Туннель UDS** | сервер брокера, служба uds-tunnel, порт 4443 (снаружи 10447); /opt/uds/uds-tunnel-server | исходники OpenUDS 5 (Rust), собран на сервере | без изменений; своё шифрование (не использует сертификат сайта). В целевой схеме — отдельные ВМ |
| **Штатные веб-интерфейсы UDS** | сервер брокера: страница входа, классический портал, админка /uds/adm/ | в составе брокера | вход используется как есть; портал сотрудника заменён нашим (nginx: /uds/page/services → /my/) |
| **Агент UDS (actor)** | на каждом рабочем столе (Windows, Linux) | OpenUDS 5.0 actor (VirtualCable) | патчи cloududs/actor/patches: пароль локальной учётки от менеджеров случайных паролей; сборка Linux под glibc 2.24 (Astra) — actor/build |
| **Клиент UDS Launcher + FreeRDP 3.27** | компьютеры сотрудников: Windows, macOS, РЕД ОС, Astra, Альт | github.com/VirtualCable/uds-client и freerdp-integration (базовые коммиты — client/patches/\*.BASE) | патчи client/patches: масштаб по DPI, физический размер монитора, плавный скролл, клавиши macOS, камера/микрофон на Mac, утечка памяти графики, вход NTLM на Windows; сборки client/build; раздаются с брокера (ссылки на портале) |

## Написано нами

Репозиторий github.com/jaland-hara/cloududs (приватный). Секретов в репозитории нет: пароли и токены — только на сервере.

| Компонент | Где работает | Откуда установлен | Что изменено / дописано нами |
|----|----|----|----|
| **Кабинет администратора и портал сотрудников** | сервер брокера, служба vdi-panel (FastAPI, 127.0.0.1:8100 за nginx), /opt/vdi-panel; настройки /etc/vdi-panel, данные /var/lib/vdi-panel | репозиторий cloududs: panel/; установка panel/deploy/install.sh | всё целиком: пулы, образы, политики, сети, пользователи, администраторы и второй фактор, уведомления, журнал и SIEM, состояние системы, сертификаты; портал со столами, запросами и сменой пароля |
| **Провайдер «VMware vSphere» для UDS** | брокер: /opt/uds/broker/src/uds/services/VSphere | репозиторий cloududs: broker/services/VSphere; установка broker/install-modules.sh | в открытом UDS 5 поставщика VMware нет — написан заново: версия пула = полная копия эталона + снимок, столы — связанные, полные или мгновенные клоны, профиль NVIDIA vGPU на версию пула; MAC из диапазона UDS, размер vCPU/памяти, питание через VMware Tools, проверка сертификата vCenter; скрипты роли и эталона — deploy/vsphere |
| **Агент «Программы и настройки»** | рабочие столы (Windows, Linux) | panel/agent/vdi-agent.ps1, vdi-agent.py; ставится командой подготовки образа | установка программ, файлов настроек и сертификатов на столы по назначению из кабинета |
| **Агент состояния серверов** | брокер, HTML5-шлюз (служба vdi-hostagent) | panel/agent/vdi-hostagent.py; команда из «Состояние системы» → «Добавить сервер» | нагрузка, службы, контейнеры, СУБД → страница «Состояние системы» |
| **Помощник сертификатов** | брокер: /usr/local/sbin/vdi-certctl, запускается systemd по заданию кабинета (от root) | panel/deploy/vdi-certctl (ставит install.sh) | выпуск и продление Let’s Encrypt через Cloudflare, загрузка своих сертификатов, переключение nginx |
| **Документация и схемы** | — | репозиторий cloududs: docs/ | целевые топологии, поток трансляции, поставка |

## Откуда может быть установлено

- **Сейчас (пилот):** брокер и туннель собраны из исходников OpenUDS 5 с нашими патчами, панель — install.sh из репозитория, шлюз — setup-guac.sh.
- **Планируется — скрипты из GitHub:** один набор sh-скриптов разворачивает всё в проекте организации (сети, ВМ, брокер, туннели, шлюзы, панель).
- **Планируется — готовые образы:** преднастроенные образы ВМ брокера, туннеля и шлюза; при первом запуске мастер подключает облачный проект организации.
- **VMware vSphere:** провайдер ставится в брокер вместе с другими нашими модулями (broker/install-modules.sh); служебная учётная запись, роль и эталонная ВМ — скриптами deploy/vsphere.
